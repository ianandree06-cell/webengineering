# Projektidee: Unterstützung bei der Wiederbelebung
Die Website ermittelt den Standort des Nutzers und zeigt über die Overpass-API von OpenStreetMap eine nach Entfernung sortierte Liste der nächsten Defibrillatoren mit Lage, Zugänglichkeit und Navigationslink. Zusätzlich enthält sie eine kurze Schritt-für-Schritt-Anleitung zur Wiederbelebung nach dem Schema „Prüfen – Rufen – Drücken“, damit Helfer bis zum Eintreffen des Defis richtig handeln können.
